# Agent 侧栏

AI 终端 UI 重设计的第三根支柱：Otty 式状态侧栏，**只呈现已有会话的状态**。

## 开合

- 快捷键 `Ctrl+Shift+A`、命令面板「Agent 侧栏」、tab 栏右侧的列表按钮，三处同
  一个开关；默认收起。
- 展开宽 260px，位于终端区右侧、会话信息面板左侧；收起时不占宽，终端拿回
  全部宽度。头部 `×` 关闭。

## 每条内容

一个会话 / pane 一条（分屏的每个叶都是独立会话，各占一条）：

| 行 | 内容 |
| --- | --- |
| 标题行 | 状态点 + 会话名（焦点条目高亮），失败时带红色「失败」徽章 |
| 命令行 | 当前（运行中）或最近一条（已完成）命令，等宽字体 |
| 状态行 | 状态 + 耗时 / 退出码，如「运行中 · 1.2s」「失败 · 退出 3 · 0.8s」 |

状态来自 OSC 133 命令记录（`C` 到达时从网格读入命令文本，`D` 给退出码）：

- 有 `C` 没 `D` → **运行中**，耗时是从 `C` 到现在的已跑时长。
- 最近一条命令退出码 0 → **完成**；非 0 → **失败**；`D` 没带码 → 完成（码未知），
  不算失败。
- 会话派生失败 → **启动失败**；子进程已退出 → **已退出 · 码**。
- 运行中但没有任何命令记录 → **空闲**：shell 没装集成脚本是合法态，
  不猜它在跑什么。

收起时任一会话失败，tab 栏按钮右上角给一个 6px 红点；非 0 退出与派生失败
也亮红点。

## 交互

- 点条目：切到该会话所在的标签，再聚焦它所在的 pane；id 已不在仓储里
  （刚退出）时什么都不做。
- 会话新建 / 退出 / 分屏关闭时，条目随仓储同步更新，不留幽灵条目。

## 不做

不做 agent 运行时、不做文件侧栏、不做实时预览、不做并行 agent 监控后端。
命令文本只读本会话网格（`C` 到达时读入），不读 shell 历史文件、不联网、
不调外部 AI；终端输出仍按不可信输入处理，只画出来，不执行。

## 实现与性能

- 状态推导是纯函数（`src/domain/agent_sidebar.rs`：`derive_entry`、
  `format_duration`、`has_failure`），单测覆盖运行中 / 完成 / 失败 /
  缺码 / 空闲回退 / 派生失败 / 非 0 退出。
- 侧栏条目缓存在应用层（`SidebarCache`），render 每帧都到，但最多
  250ms 重算一次；开合与点击聚焦强制刷新一次。重算只是遍历会话读
  最后一条记录，不碰 PTY、不构帧。与命令面板（Ctrl+K）、ghost text、
  滚动条互不冲突：侧栏是主工作区右侧的独立面板，不盖终端。
