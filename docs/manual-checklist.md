# 发版手动检查清单

自动化测试覆盖不了的部分。每次发版在真实桌面会话里逐条过一遍，
任何一条失败都不要发版。

记录格式：`通过 / 失败（现象）/ 不适用`。

## 1. 启动与单实例

- [ ] 干净配置下 `siskin` 打开一个窗口，出现登录 shell 提示符。
- [ ] 提示符样式来自用户自己的 shell（不是应用画的假提示符）。
- [ ] 再执行一次 `siskin`：不出现第二个窗口，已运行窗口获得焦点。
- [ ] `siskin -d /tmp` 在已有实例运行时也走转发路径，不新起进程。
- [ ] `siskin -e ` 加不存在的命令：窗口保留并显示失败原因。
- [ ] `siskin -V` 输出版本号，退出码 0。

## 2. 真实程序

- [ ] `vim` 打开文件、编辑、`:wq` 退出，状态行不重叠。
- [ ] `htop` 布局正常，方向键与 `F` 键可用，退出后终端状态恢复。
- [ ] `tmux` 新会话、分屏、状态栏位置正确；`Ctrl+B` 不被应用吞掉。
- [ ] `ssh localhost`（或任意主机）能登录，`Ctrl+C` / `Ctrl+Z` / `Ctrl+D` 行为正确。
- [ ] `less` 翻页正常，`q` 退出后光标位置正确。
- [ ] `git log` 的颜色与分页正常。

## 3. 中文与输入法

在 fcitx5 与 ibus 下各跑一遍（X11 与 Wayland 分别记录）。

- [ ] 组词过程中字符不写入 shell，候选框跟随光标。
- [ ] 退格能逐步缩短预编辑串。
- [ ] 选定候选词后只提交最终文本。
- [ ] `Ctrl+Space` 切换输入法不被终端吞掉。
- [ ] 中文宽度占两列，后续文本不错位。

## 4. 选区与剪贴板

- [ ] 拖选高亮连续，跨行选择正确。
- [ ] `Ctrl+Shift+C` 复制，粘贴到浏览器与编辑器内容一致。
- [ ] `Ctrl+Shift+V` 粘贴多行命令不会自动执行。
- [ ] 中键粘贴 PRIMARY 内容。
- [ ] 在 `vim` 鼠标模式下 `Shift+拖选` 仍能本地选字。

## 5. 滚动与搜索

- [ ] 滚轮滚动按行移动，不回弹。
- [ ] `Shift+PageUp/PageDown` 翻页，`Shift+End` 回到输出底部。
- [ ] 新输出到达时自动贴回底部（未手动上滚时）。
- [ ] `Ctrl+Shift+F` 打开搜索条，输入匹配高亮，`Enter` 跳到下一个。
- [ ] 搜索中文能命中，高亮宽度与字符宽度一致。

## 6. 链接

- [ ] `Ctrl+Click` 打开 `https://` 链接，使用系统默认浏览器。
- [ ] `Ctrl+Click` 打开 `path:line:col` 形式的本地文件。
- [ ] `javascript:`、`data:` 之类协议不被打开。
- [ ] 相对路径按会话 cwd 解析。

## 7. 窗口与尺寸

- [ ] 拖动窗口边界后 `stty size` 报告新行列数。
- [ ] 缩放窗口不出现内容错行或最后一列被截断。
- [ ] 最小尺寸 960×640 下侧栏与终端都完整可见。
- [ ] `Ctrl+=` / `Ctrl+-` 改字号立即重排，行列数同步变化。

## 8. 设置与持久化

- [ ] 改主题、字体、字号、Shell 后重启，设置全部保留。
- [ ] 拖动取色时不出现卡顿（保存已防抖）。
- [ ] 设置文件写入只读目录时，设置页显示「未能保存设置」。
- [ ] 手动写坏 `settings.json` 后启动：应用仍能用，原文件不被覆盖。
- [ ] 关闭前 500ms 内的最后一次改动，重启后仍在。
- [ ] 关闭窗口再打开，会话标题与目录按上次恢复。

## 9. 桌面集成（X11）

- [ ] 开始菜单能找到 Siskin，图标是新稿。
- [ ] 任务栏窗口图标与开始菜单一致。
- [ ] DDE 顶栏菜单出现「文件 / 编辑 / 视图」。
- [ ] 从菜单切换主题、切换 Shell，窗口内状态同步。
- [ ] 顶栏服务重启后菜单自动重新注册。
- [ ] Wayland 下不注册全局菜单，命令面板仍可用。

## 10. 安装包

- [ ] 干净系统 `apt install ./siskin_x.y.z_amd64.deb` 成功。
- [ ] 安装后开始菜单出现，Plank 能固定。
- [ ] `16/22/24/32/48` 图标不是模糊位图放大。
- [ ] 卸载后开始菜单条目与图标缓存都清掉。

## 11. 异常路径

- [ ] `SHELL=/nonexistent` 启动：显示可读错误，不崩溃。
- [ ] 没有 D-Bus 会话总线：应用仍能启动，仅菜单不可用。
- [ ] 无 Vulkan 驱动：给出可读提示，不是 panic。
- [ ] 磁盘只读：设置保存失败有提示，终端仍可用。

## 12. 长输出压测

- [ ] `seq 1 200000` 不卡死，滚动到底部。
- [ ] `yes | head -n 200000` 不丢行。
- [ ] 连续运行 8 小时后内存增长可解释（无持续泄漏）。
